# ROXAMI 🌍

### Simple tools. Open to everyone.

ROXAMI is an independent open-source software studio dedicated to building free, simple, and accessible applications for everyone.

We believe useful technology should be accessible to all. Our goal is to create practical software that makes everyday tasks easier while keeping it open for everyone to use, explore, and contribute to.

## 🚀 Our Mission

To make everyday technology simpler, more accessible, and freely available through open-source software.
